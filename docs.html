1. Overview #

TubePilot is a Windows desktop studio for faceless YouTube channels. You give it a niche and, optionally, an exact topic. It then runs the whole production line:

topic → script → SEO → neural voiceover → AI or stock visuals → 1080p MP4 → thumbnail → YouTube upload.

Everything runs on your own PC. Settings, keys, projects, voiceovers and finished videos live in one folder under %APPDATA%\TubePilot. The app bundles its own Java runtime, FFmpeg and an offline sample library, so the installed PC needs no developer tools and can still render a video without internet.

Prefer to watch first? The narrated walkthrough takes you from installation to upload in 1:47. An Arabic version (2:24) is in the same player, and every step below follows the same order.

What TubePilot does not do. It never automates views, likes, comments, subscriptions or watch time. Uploads go through the official YouTube Data API v3 only. The app is a production tool, not an engagement bot.

What each stage produces

StageWhat happens
IdeaYour AI provider picks a topic inside the niche, or uses the topic you typed.
ScriptA hook-first narration split into timed scenes, each with its own visual description.
SEOTitle, description, tags and the short overlay text used on the thumbnail.
VoiceFree Microsoft Edge neural narration with word-level timings that become an SRT subtitle file. Offline Windows voices are the fallback.
VisualsAI images or clips per scene, then stock video and photos, then the bundled samples.
RenderBundled FFmpeg writes 1920×1080 at 30 fps, H.264/AAC, with optional music and burned-in subtitles.
ThumbnailA 1280×720 JPEG made from a strong scene image, a gradient and your overlay words.
UploadResumable upload with metadata and thumbnail, private by default.

A failed optional stage never discards finished work. The MP4 stays on disk and the error is shown on the project.

2. Requirements #

Computer

  • Windows 10 or Windows 11, 64-bit.
  • About 700 MB of free disk space for the app, plus room for videos (roughly 40–120 MB per finished video).
  • 4 GB of RAM is enough to run and render; 8 GB is more comfortable with a browser open.
  • No GPU is required. Rendering is CPU-based; a GPU only helps the window itself.
  • Internet for AI generation, online stock sources, online neural voices and YouTube.

Accounts and keys

  • One AI key is required for your own videos. Gemini's free tier is enough for scripts and SEO.
  • Optional: an AI image/video key with billing for AI-generated visuals.
  • Optional: free Pexels, Pixabay and Unsplash keys for the widest stock choice. Openverse, Wikimedia Commons and NASA need no key.
  • Optional: a Google Cloud OAuth client for automatic YouTube uploads.

Builds from source only. Running from source needs JDK 21 and Gradle. The downloadable installer and portable ZIP include their own runtime; you do not install Java on the target PC.

Install with the setup EXE

  1. Download TubePilot-Setup-1.0.1.exe from the downloads section.
  2. Double-click it. Windows may show Windows protected your PC because the build is not code-signed yet. Click More info → Run anyway.
  3. Accept the default folder, or choose another one. The installer writes to your user profile, so no admin password is needed.
  4. When it finishes, launch TubePilot from the Start menu.

Run the portable build

  1. Right-click the ZIP → Extract All. Do not run the app from inside the ZIP preview.
  2. Open the extracted TubePilot folder.
  3. Double-click TubePilot.exe.
  4. To move it later, move the whole folder; the app needs the files next to the EXE, including app\resources\tools\ffmpeg.exe.

Verify the download (optional)

Open PowerShell in the download folder and compare the hash with the value on the download page:

Get-FileHash .\TubePilot-Setup-1.0.1.exe -Algorithm SHA256

First launch notes

  • Settings and videos are created in %APPDATA%\TubePilot on first run.
  • If the window is blank on a remote desktop or virtual machine, close it and set TUBEPILOT_SOFTWARE_RENDER=1 before launching. That switches the UI to CPU rendering.
  • Windows SmartScreen will keep warning until the build is code-signed. The warning is about signing reputation, not a virus report.
  • Antivirus may scan ffmpeg.exe on first render. Allow the app folder and %APPDATA%\TubePilot\tools if it blocks anything.

Uninstall

  • Installer build: Settings → Apps → Installed apps → TubePilot → Uninstall. For a fully clean removal, delete %APPDATA%\TubePilot afterwards (this deletes keys, projects and videos).
  • Portable build: delete the extracted folder, then delete %APPDATA%\TubePilot if you also want to remove your data.

4. Trial and license #

On first launch the window opens on Subscription. New video and Settings stay locked until you start the trial or activate a purchased key.

Start the 48-hour free trial

  1. Open Subscription in the sidebar (it is where the app starts).
  2. Press Start 48-hour free trial.
  3. A live countdown appears in the sidebar, on Home and on Subscription. No card and no account are needed.

The trial is a one-time offer per Windows profile. Once it has been used or has expired, the trial button and every “start free trial” prompt disappear; only the Monthly and Yearly plans remain.

Activate a purchased key

  1. Open Subscription.
  2. Paste the TP1… key into Activate a license.
  3. Press Activate. The Ed25519 signature is verified offline; no internet is needed.

You can also activate from a terminal in the app folder:

TubePilot-cli.cmd --activate TP1...
TubePilot-cli.cmd --subscription

The second command prints the current plan, expiry and whether pipeline access is unlocked.

When access locks

When the trial or license reaches zero, the sidebar countdown turns red in the last hour and access locks immediately at expiry. Creating videos, the pipeline, uploads, headless runs and opening existing projects all require an active plan. The app stays on Subscription until a new key is entered. Nothing is deleted.

Payment is handled directly on WhatsApp (+961 3 091 136) by OMT, Whish Money, USDT or bank transfer. The key from that chat unlocks the Windows and Android apps. Keys verify offline and are honour-based: they cannot be forged or revoked, so one key can technically be used on more than one PC.

Sign out on this PC clears the local license so the key can be entered on another computer.

5. First-time setup #

Open Settings and work down the cards. Only the AI provider is required for your own videos; everything else is optional or already bundled.

5.1 AI provider (required)

  1. Pick a provider: Gemini (free) is the simplest, OpenAI (ChatGPT) works with an OpenAI key, and Zen/Go are OpenCode gateways with their own billing.
  2. Paste the key into the field. Keys are stored locally in settings.properties.
  3. Choose a model. gemini-3.6-flash is a good default; Load models asks the provider what your key can use.
  4. Press Test key & model. You want a short success message, not a 401/429/402.

Get a free Gemini key at aistudio.google.com/apikey. Get an OpenAI key at platform.openai.com/api-keys; API usage is billed separately from a ChatGPT Plus subscription.

5.2 AI-generated footage (optional)

The AI-generated footage card lets TubePilot draw every scene from that scene's own script prompt instead of searching for stock. It is optional and off in practice until a key has image quota.

  • Illustrate each scene from its script — master switch for AI stills. On by default; it only runs when a usable key exists.
  • Gemini image model — default gemini-2.5-flash-image. If the saved name is retired, a current image model is found automatically.
  • OpenAI image model — default gpt-image-1, used with an OpenAI key.
  • Real AI video clips (premium) — off by default; asks Gemini Omni Flash for a short clip per scene instead of a still.
  • Resolution / clip length — 360p, 720p or 1080p and 4/6/8/10 seconds, with an estimated cost shown on the card.
  • Test AI visuals — checks the configured model without billing an image.

Billing required for AI visuals. Gemini's free tier allows zero image and video requests (HTTP 429). Enable billing on the Google AI Studio project, or add a paid OpenAI key. Scripts and SEO still work on the free tier. Without billing, the video simply uses stock footage.

5.3 Narration

  1. Leave Edge neural (free) selected. It needs no key and covers 16 languages.
  2. Pick a voice and press Test voice. Edge voices need internet.
  3. If the test fails, switch to Windows voices (offline) and choose an installed SAPI voice. --setup reports which engine works.
  4. Adjust Speed if you want a faster or slower read.

5.4 Stock visuals

Below the AI card, enable the sources you want and paste any free keys. Pexels, Pixabay and Unsplash need keys; Openverse, Wikimedia Commons, NASA and the bundled samples do not. Press Test enabled sources.

  • Pexels API — free key, credit link required (added automatically).
  • Pixabay API — free key, credit line added automatically.
  • Unsplash — free access key, photographer credited automatically.
  • Openverse, Wikimedia Commons and NASA — no key.
  • Bundled samples — 44 clips installed with the app, works fully offline.

5.5 FFmpeg

FFmpeg is bundled at app\resources\tools\ffmpeg.exe. Leave it alone and press Detect once. A passing H.264 self-test means rendering is ready. If the bundled copy is ever lost, the app can download one into %APPDATA%\TubePilot\tools.

Some other apps install a stripped FFmpeg (CapCut is a common one). TubePilot detects and ignores builds without libx264, so always let it use its own copy.

5.6 Automation and music

  • Upload after rendering — leave on for a straight-through run; off to review the MP4 first.
  • Default visibility — Private (recommended), Unlisted or Public.
  • Background music — point the music folder at a folder of royalty-free MP3s, then set the volume. One track is picked and mixed low under the narration.
  • AI disclosure — on by default; appends a short “created with AI assistance” line when AI was used.

5.7 YouTube (optional at first)

Skip this to render locally. To enable uploads, create a Google Cloud OAuth Desktop app client, paste its client ID and secret into Settings → YouTube, and press Connect YouTube. Full steps are in section 12.

5.8 Save

Press the save button in the Settings header. Changes are written to settings.properties.

6. Your first video #

  1. Press New video in the sidebar.
  2. Niche / channel topic — for example personal finance for beginners. Required unless you type a topic.
  3. Video topic — optional. Leave it empty and the AI chooses one. Or press Brainstorm 12 ideas with AI and click a result.
  4. Target audience — optional, default “General audience”.
  5. Tone — Educational, Storytelling, Documentary, Listicle, Motivational, Explainer, News recap or Mystery.
  6. Language — the narration language, not the app language. 16 options, including Arabic, Hindi, Urdu, Turkish and Chinese.
  7. Target length — 2 to 20 minutes. Six minutes is a good default.
  8. Leave Run the full pipeline automatically on.
  9. Press Create & run everything.

The project opens on the Auto tab. Each stage reports progress, and the stop button halts cleanly without discarding finished files. When it ends you get the MP4 path, the thumbnail path and, if uploaded, the YouTube URL.

How long does it take? A six-minute video usually needs a few minutes for script, SEO and voice, plus several minutes of CPU encoding. A 20-minute 1080p render is much longer. Keep the PC awake and online until the upload finishes.

Review, fix, publish

  • Script — read the hook and scenes, edit any narration or visual line, then save.
  • SEO — adjust title, description and tags; add chapter timestamps from the scene list.
  • Voice — regenerate the voiceover after editing the script, or swap the voice and speed.
  • Video — rebuild the visuals and render again; watch the MP4 or open the project folder.
  • Thumb — regenerate the thumbnail with different overlay text.
  • Publish — upload manually, or re-upload with different metadata if the first attempt failed.

Home

The landing screen shows your plan and countdown, the eight-stage pipeline summary and shortcuts to a new video, existing projects and Settings. The sidebar carries the English/العربية switch, Home, New video, Settings, Subscription and the data-folder button.

The form described in section 6, with an AI idea generator and a language picker. The right-hand cards show the AI key, visual chain, FFmpeg and YouTube status so you can see what is missing before starting.

8. Language and right-to-left layout #

The sidebar has an English / العربية switch. It changes the whole window — Home, New video, every project tab, Settings and Subscription — and Arabic is laid out right-to-left. The choice is saved in ui_language and restored on the next launch.

  • Only the interface is translated. AI-generated titles, scripts and topics stay in the narration language you chose.
  • File dialogs are translated too: their titles and filters follow the app language.
  • The language switch is independent of the video language on New video.

The built-in demo video is no longer a Home-screen button. It remains available for walkthroughs and smoke tests from the command line: 

TubePilot.exe --demo
TubePilot.exe --demo --language ar

In the app folder, TubePilot-cli.cmd --demo does the same. Setting TUBEPILOT_DEMO_AUTOSTART=en or ar starts the demo automatically after the window opens. The demo needs an active trial or plan.

9. AI and stock visuals #

Every scene gets a visual, even when keys are missing or quota runs out. TubePilot walks a fixed chain and takes the first usable result:

AI video → AI stills → Pexels → Pixabay → Unsplash → bundled samples → Openverse → Wikimedia Commons → NASA.

AI stills

The image prompt is built from the scene's own visual description plus its narration, the topic and the tone. The returned picture is normalised to 1920×1080 and animated with a slow Ken Burns push, pull or pan. Pictures are cached in cache\stock\ai\ keyed by the full prompt, so re-rendering an unchanged project costs nothing.

AI video

When Real AI video clips is on, Gemini Omni Flash (gemini-omni-1.2-flash) is asked for a short clip per scene. It is premium, off by default, and stops being retried for that render after the first failure. Clips are cached in cache\stock\ai_video\.

Stock and bundled footage

Stock results are searched with each scene's visual phrase. A suitable video is trimmed to the scene length; a photo gets the Ken Burns move. Pexels, Pixabay and Unsplash credits are appended to the description automatically. The bundled sample library (44 clips) is installed with the app and is the offline safety net. A generated title card is drawn only if every other source misses.

Failures

Quota, retired models, rate limits, content filtering and network errors are logged with one line and fall through to the next source. A failed visual never fails the render, and thumbnails stay on stock images so a render never silently spends money on an extra image.

AI image/video needs billing. Gemini's free tier allows zero image requests. If every AI attempt falls back to stock, check the render log for the reason and confirm billing on the AI Studio project — or use a paid OpenAI key for stills.

10. Command line #

The same engine runs headless from the app folder. Use TubePilot-cli.cmd in the installed or portable build: 

TubePilot-cli.cmd --niche "personal finance" --minutes 8
TubePilot-cli.cmd --niche "ancient history" --topic "why Rome fell" --minutes 9 --no-upload
TubePilot-cli.cmd --setup
TubePilot-cli.cmd --subscription
TubePilot-cli.cmd --activate TP1...

From a source checkout, use Gradle instead:

$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
cd E:\Business\TubePilot
.\gradlew.bat :desktop:runAuto --args='--niche "personal finance" --minutes 8'
OptionMeaning
-n, --niche <text>Channel topic. Required unless --topic is set.
-t, --topic <text>Exact video topic. When omitted, the AI chooses one.
-a, --audience <text>Target audience. Default General audience.
--tone <text>Tone. Default Educational.
--language <tag>Narration language tag such as en-US, ar-SA, es-ES. Default en-US.
-m, --minutes <2-20>Target length. Default 6.
--no-uploadRender locally, skip YouTube.
--privacy <mode>private, unlisted or public for this run only.
--setup, --checkReadiness check: keys, FFmpeg, Edge TTS, visuals and subscription.
--demoRender the built-in demo. Add --language ar for Arabic.
--activate <key>Activate a license key on this PC.
--subscriptionPrint the plan and whether access is unlocked.
-h, --helpShow usage.

--no-upload and --privacy apply only to that invocation; saved Settings are restored afterwards. --setup exits with code 0 when required items are ready and 1 when something marked MISSING or FAILED needs attention. It is safe to run repeatedly.

Headless runs use the same settings.properties as the window, so activating a plan in the app also unlocks scheduled runs. Scheduled runs need an active trial or plan.

11. Scheduled runs #

For a daily or weekly unattended video, point Windows Task Scheduler at TubePilot-cli.cmd (installed build) or at the repository's run-auto.ps1 (source build). Example for the installed build: 

powershell.exe -NoProfile -ExecutionPolicy Bypass -Command "& 'C:\Users\YOU\AppData\Local\TubePilot\TubePilot-cli.cmd' --niche 'personal finance' --minutes 8"
  1. Open Task Scheduler → Create Task.
  2. General — choose Run whether user is logged on or not.
  3. Triggers — daily at a time the PC is on and online.
  4. Actions — start powershell.exe with the arguments above.
  5. Start in — the app folder, so relative paths resolve.
  6. Activate the plan once with --activate, then confirm with --subscription.

Keep the machine awake and connected. A dropped network stops the run cleanly; the finished MP4 stays on disk and the run can be retried. Roughly six uploads a day fit YouTube's quota.

12. YouTube connection #

Uploading needs your own Google Cloud OAuth client. It is a one-time setup and free.

  1. Open console.cloud.google.com and create or select a project.
  2. APIs & Services → Library → search YouTube Data API v3 → Enable.
  3. APIs & Services → OAuth consent screen: choose External, add your Google account as a test user, and add the scopes youtube.upload and youtube.readonly.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID → application type Desktop app.
  5. Copy the Client ID and Client secret into Settings → YouTube and press Connect YouTube.
  6. A browser opens Google's consent page. TubePilot catches the redirect on a one-shot http://127.0.0.1:<port> listener and stores the refresh token.

The flow uses PKCE with access_type=offline and prompt=consent, so it survives restarts. While the consent screen is in Testing, refresh tokens expire after 7 days and only listed test users can authorise — publish the app or reconnect weekly. Workspace accounts may need an administrator to allow the API.

Upload behaviour

  • Resumable upload with title, description, tags, category and privacy.
  • Private by default. Unlisted, Public and scheduled publishing are available.
  • The thumbnail is set after the video is uploaded. Unverified channels may reject custom thumbnails; the video still uploads.
  • A failed upload never loses the MP4; retry from the Publish tab.

13. Files, backups and reset #

Everything is self-contained under %APPDATA%\TubePilot:

%APPDATA%\TubePilot\
├─ data\settings.properties     API keys, voice, automation, OAuth tokens, license cache
├─ data\projects.json           project list and per-project state
├─ media\<id>\                  voiceover, SRT, thumbnail, rendered MP4
├─ cache\stock\<source>\       downloaded stock footage and photos per provider
├─ cache\stock\ai\              AI-generated scene images (one per prompt)
├─ cache\stock\ai_video\        AI-generated scene clips, when video is enabled
├─ samples\                    optional user override for the bundled sample library
├─ tools\                      fallback ffmpeg.exe / ffprobe.exe
├─ music\                      optional background music
└─ temp\                       per-scene TTS and render scratch files
  • Back up: close the app, then copy the whole %APPDATA%\TubePilot folder.
  • Move to another PC: install TubePilot there, close it, then copy the folder over.
  • Start fresh: close the app and delete %APPDATA%\TubePilot. This removes keys, projects, caches and videos.
  • Open the folder: use Open data folder in the sidebar.
  • Free space: the cache\stock folders are the largest; deleting them only costs a re-download next time.

Settings store keys in plain text inside your Windows profile. Protect the PC account and do not share the folder.

14. Quota, uploads and channel limits #

  • Quota. The YouTube Data API grants 10,000 units per Google Cloud project per day. An upload costs roughly 1,600 units, so expect about 6 uploads per day. Thumbnail and channel calls add a little more. Quota resets at midnight Pacific.
  • Fresh channels. Custom thumbnails require channel verification, and videos longer than 15 minutes do too. TubePilot caps runs at 2–20 minutes, but a brand-new channel may still reject the thumbnail until verified.
  • AI disclosure. Settings can append a short “created with AI assistance” line. It is on by default and covers narration; when AI visuals were used it mentions them too.
  • Stock credits. A credit line naming the provider and photographer/channel is appended whenever stock media is used, as required by the Pexels, Pixabay, Unsplash, Openverse, Wikimedia Commons and NASA licences.
  • No engagement automation. TubePilot does not automate views, likes, comments, subscriptions or watch time.

16. FAQ #

Do I need API keys to try it?

You need one AI key for your own videos; Gemini's free tier is enough. The built-in demo renders with no keys. Stock footage, the bundled samples and the demo work without stock or voice keys.

Does it upload without asking?

Only when uploading is enabled. Uploads default to Private. You can turn off Upload after rendering, use --no-upload, or skip the YouTube connection entirely and only render locally.

Which languages can the videos be in?

Sixteen narration languages: English (US and UK), Spanish, French, German, Italian, Portuguese, Arabic, Hindi, Urdu, Turkish, Indonesian, Russian, Japanese, Korean and Chinese. The app interface switches between English and Arabic.

Will it work without a GPU?

Yes. Rendering uses the CPU and bundled FFmpeg. A GPU only helps the window itself; on remote desktops or VMs with no 3D support, set TUBEPILOT_SOFTWARE_RENDER=1.

Can it run fully offline?

The renderer, bundled sample library and FFmpeg are local, so a video can be rendered offline. Scripts and SEO need your AI provider, stock downloads need internet, and Edge voices are online. Windows SAPI voices cover offline narration.

How many videos can I upload per day?

About six per Google Cloud project per day (10,000 units, roughly 1,600 per upload). Local renders are unlimited.

Can I use the same key on Windows and Android?

Yes. The license is verified offline and is not tied to a single platform.

What happens to my videos if the subscription expires?

Nothing is deleted. The app locks new runs until a new key is activated, but existing projects and MP4s remain in %APPDATA%\TubePilot.

Does the app translate my script into Arabic?

No. The interface switches language; the narration stays in the language you choose on New video. Choose ar-SA there for an Arabic voiceover.

API keys, OAuth tokens, projects, voiceovers, videos and caches live only on your PC under %APPDATA%\TubePilot. TubePilot has no account system and no server of its own. Requests go directly from your PC to the providers you configured: Google Gemini/YouTube, OpenAI, OpenCode, Pexels, Pixabay, Unsplash, Openverse, Wikimedia Commons, NASA and Microsoft's Edge speech endpoint.

Third-party terms

Your use of those services is governed by their terms and quotas, including YouTube's Community Guidelines, the YouTube API Services Terms, and the licences of each stock provider. AI-generated images and video are subject to the image provider's terms. Stock credits are added automatically where required.

Content responsibility

You are responsible for the topic, script, narration and visuals you publish, and for disclosing AI assistance where required by law or platform policy. TubePilot does not verify facts in generated scripts. Review before publishing.
